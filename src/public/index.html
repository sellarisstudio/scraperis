About Scraperis

Scraperis 🚀

Automated Google Maps & Google Search Business Lead Extractor

Powerful

Built with Playwright for reliable browser automation and data extraction.

Open Source

MIT License. Free to use, modify, and distribute for any purpose.

Developer Friendly

Built with Node.js, Express, and modern web technologies.

Key Features

  • ✓ Dual Scraping Modes: Google Maps and Google Search with social media targeting
  • ✓ Multi-Keyword & Multi-Location: Scrape combinations of keywords and locations
  • ✓ Leads Basket: Accumulate and manage leads from multiple runs
  • ✓ CSV & Excel Export: Export with customizable columns
  • ✓ Real-time Progress: Monitor scraping with live logs and visualization
