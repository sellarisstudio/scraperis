Scraperis Application Demo

Built with Powerful Lead Scraping Features

Scraperis combines cutting-edge headless scraping technology with a user-friendly browser control interface, making lead collection effortless.

Google Maps Scraper

Extract extensive business lists from maps including name, category, rating, total review count, physical address, phone numbers, and official websites.

Google Search Scraper

Target social media networks (Instagram, Facebook, LinkedIn, TikTok) with customized category tags and contact prefixes (e.g. WhatsApp, WA.me) to gather direct contact info.

Sequence Scraping

Input multiple search keywords and geographical locations simultaneously. The app runs systematically to resolve and scrape every combination sequence.

Persistent Leads Basket

Accumulate collected records across multiple scraper executions. A local storage-based basket automatically filters duplicates, keeping your data clean.

Custom CSV & Excel Export

Select which data columns you need, configure file properties, and export seamlessly from active run outputs or your consolidated Leads Basket.

Developer-Friendly SSE Logs

Engineered with Node.js, Express, and Playwright. Offers real-time progress visuals and raw server logs delivered via Server-Sent Events (SSE).

Get Started with Scraperis

Choose between downloading the ready-to-run Windows installer or launching the developer repository locally on your computer.

1

Download the Windows Installer

Get the latest ready-to-run installation bundle directly from our GitHub Releases page.

Download Latest Release (.exe)
2

Run the setup executable

Double-click the downloaded `.exe` installer. If Windows SmartScreen prompts a warning, click on More Info and click Run Anyway (This is normal since the installer is self-signed).

3

Launch and Start Extracting

Open Scraperis from the desktop shortcut or Start Menu, paste your target categories/locations, and build your list immediately!

1

Prerequisites

Make sure you have Node.js (v16 or higher) installed on your development workstation.

2

Clone and Install Dependencies

Execute these terminal instructions to download the source files and install required nodes: 

git clone https://github.com/sellarisstudio/scraperis.git
cd scraperis
npm install
3

Install Playwright Browsers

Run the background installation sequence to download headless Chromium browsers managed by Playwright: 

npm run install-browser
4

Start Local Server / Electron Environment

To launch the dev server backend on http://localhost:3000: 

npm run dev

To launch the desktop dashboard wrapper via Electron: 

npm run electron:dev
